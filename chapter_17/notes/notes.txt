// requesting data using an api call

githubs api lets you request a wide range of info through api calls
eg https://api.github.com/search/repositories?q=language:python+sort:stars
"total_count": 25010465,

https://api.github.com : directs the request to the part of GitHub that responds to api calls
search/repositories : tells the api to conduct a search through all the repositories on github
? : signals that we are about to pass an argument
(q=) : stands for query
language:python : we indicate that we want information only on repositories that have 
python as the primary language
+sort:stars, sorts the projects by the number of stars they've been given
